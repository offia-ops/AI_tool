🤖 利用 AI 打造實用網頁小工具 (AI-Driven Web Widget Builder)

這是一個示範如何利用 AI (如 Gemini) 作為寫碼助手，快速從「概念」到「成品」打造實用網頁小工具（Web Widgets）的專案指南。

本指南以開發 台新股票交易手續費計算器 為實際案例，展示了完全不依賴複雜的開發環境（No Node.js, No Webpack），僅透過 Prompt (詠唱提示) 與迭代，產出具備現代化 UI 與複雜商業邏輯的單檔應用程式（Single-file App）。

🌟 旗艦範例：台新股票交易手續費計算器

這是一個幫助投資人計算真實交易摩擦成本的互動式工具，專為台股/零股再平衡設計。

核心功能

即時運算：拖曳滑桿或輸入數字，即時顯示手續費與稅金。

券商邏輯：內建「買賣手續費 0.1425% (低消 20 元)」與「賣出交易稅 0.3%」規則。

防呆警告：當手續費佔比超過 1%（低效交易）時，UI 會變為紅色警告。

多筆清單：支援將單筆計算加入下方清單，自動加總所有交易的總成本。

技術棧 (Tech Stack)

HTML5：語意化結構。

Tailwind CSS (CDN)：快速構建現代化、RWD (響應式) 且具備流暢過場動畫的 UI。

Vanilla JavaScript：純原生 JS，無任何外部框架相依，確保最高效能與相容性。

🛠️ AI 協作開發工作流 (The AI Workflow)

使用 AI 開發不是一次到位，而是一個「溝通 ➜ 產出 ➜ 修正 ➜ 擴充」的迭代過程。以下是我們建立此工具的四個階段：

Phase 1: 建立核心原型 (Prototyping)

一開始，不要給 AI 太複雜的要求，先確保「核心數學邏輯」正確。

Prompt 範例：

「請幫我寫一個單檔的 HTML 網頁，使用 Tailwind CSS 進行美化。這是一個股票手續費計算器，邏輯如下：手續費為成交金額的 0.1425%，未滿 20 元以 20 元計收。賣出時需額外收取 0.3% 交易稅。請提供輸入框與買賣切換按鈕。」

Phase 2: UI/UX 微調與優化 (Refining)

當原型出來後，針對使用者的操作體驗進行打磨。

Prompt 範例：

「請把交易金額的顯示區塊改成可以直接輸入數字的 input type="number"，並且隱藏預設的上下箭頭。另外，請把預設動作改為『賣出』。」

Phase 3: 功能擴充 (Expanding)

核心功能確認無誤後，開始疊加進階功能（如資料陣列、加總等）。

Prompt 範例：

「請加入『支援多筆計算』的功能。增加一個『加入計算清單』的按鈕，按下後會在下方產生一個表格記錄每一筆的金額與成本，並在表格最下方提供總計。」

Phase 4: 除錯與修復 (Debugging)

當 AI 在合併程式碼或擴充功能時出錯，直接將錯誤訊息丟給它。

Prompt 範例：

「畫面上沒有出現錯誤，但按下按鈕時 Console 顯示 TypeError: Cannot read properties of null (reading 'style')，指向 taxBar，請幫我修復這個問題。」
