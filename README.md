🤖 利用 AI 打造實用網頁小工具 (AI-Driven Web Widget Builder)

這是一個示範如何利用 AI (如 Gemini) 作為寫碼助手，快速從「概念」到「成品」打造實用網頁小工具（Web Widgets）的專案指南。

本指南以開發 台新股票交易手續費計算器 為實際案例，展示了完全不依賴複雜的開發環境（No Node.js, No Webpack），僅透過 Prompt (詠唱提示) 與迭代，產出具備現代化 UI 與複雜商業邏輯的單檔應用程式（Single-file App）。

🌟 旗艦範例：台新股票交易手續費計算器

這是一個幫助投資人計算真實交易摩擦成本的互動式工具，專為台股/零股再平衡設計。

核心功能

即時運算：拖曳滑桿或輸入數字，即時顯示手續費與稅金。

券商邏輯：內建「買賣手續費 0.1425% (低消 20 元)」與「賣出交易稅 0.3%」規則。

防呆警告：當手續費佔比超過 1%（低效交易）時，UI 會變為紅色警告。

多筆清單：支援將單筆計算加入下方清單，自動加總所有交易的總成本。

技術棧 (Tech Stack)

HTML5：語意化結構。

Tailwind CSS (CDN)：快速構建現代化、RWD (響應式) 且具備流暢過場動畫的 UI。

Vanilla JavaScript：純原生 JS，無任何外部框架相依，確保最高效能與相容性。
